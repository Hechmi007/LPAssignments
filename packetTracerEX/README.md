\# Exercice 01 - Packet Tracer MiniLab



\## 📌 Introduction



This exercise is part of the MSc Cyber technical validation.



The goal is to design and configure a MiniLab network using Cisco Packet Tracer with VLANs, DHCP, and Internet access.



\---



\## 🧠 Objective



\* Configure VLANs

\* Configure Router 1941

\* Configure DHCP

\* Configure Switches

\* Configure WiFi Access Points

\* Configure IP Phones

\* Test connectivity between VLANs

\* Ensure Internet access



\---



\## 🖥️ Equipment



\* Cisco 1941 Router

\* 3 Switches

\* 3 WiFi Access Points

\* 3 Laptops

\* 6 PCs

\* 3 IP Phones



\---



\## 🌐 VLAN Plan



| VLAN    | Usage | Network         |

| ------- | ----- | --------------- |

| VLAN 1  | VoIP  | 192.168.0.0/24  |

| VLAN 10 | WiFi  | 192.168.10.0/24 |

| VLAN 20 | PCs   | 192.168.20.0/24 |

| VLAN 30 | Admin | 192.168.30.0/24 |



\---



\## 🔧 Switch Configuration



Ports configuration:



\* Port 8 → VLAN 30

\* Ports 6-7 → VLAN 20

\* Ports 4-5 → VLAN 10

\* Ports 2-3 → VLAN 1

\* Ports 1 \& 9 → Trunk
